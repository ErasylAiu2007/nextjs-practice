# Next.js Practice

## 1. Project Description
This project was created to practice using Next.js.

## 2. Commands

- `npx create-next-app@latest my-next-app` — creates a new Next.js project.
- `cd my-next-app` — opens the project folder.
- `npm install` — installs dependencies.
- `npm run dev` — runs the development server.
- `npm run build` — builds the project for production.
- `npm run start` — starts the production server.

## 3. Project Structure

- `app/` — contains pages and layouts.
- `public/` — contains images and static files.
- `package.json` — contains dependencies and project commands.
- `README.md` — describes the project and its commands.
- `node_modules/` — contains installed packages.

## 4. Technologies
- Next.js
- React
- TypeScript
- Tailwind CSS
